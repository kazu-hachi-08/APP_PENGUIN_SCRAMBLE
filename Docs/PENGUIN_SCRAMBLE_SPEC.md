# ペンギンスクランブル 仕様書

> 対話で中身を決めながら埋めていく。未定の項目は「未定」と書いておく。「（案）」は Claude の提案で、まだ確認していないもの。
> 実装の順番は `PLAN_PHASES.md`。

## 1. 概要

おもちゃのペンギンを3体連れて、大量の野生ペンギンをなぎ倒していく見下ろし型アクション。最大4人のオンライン協力でステージを攻略する。仲間はガチャで集める。

| 項目 | 内容 |
| --- | --- |
| アプリ名 | ペンギンスクランブル |
| ジャンル | 乱戦アクション（斜め見下ろしの2D） |
| 雰囲気 | おもちゃのようなコミカル。丸くてかわいく、倒されても痛そうに見えない |
| グラフィック | ComfyUI（Comfy Desktop）で作った1枚絵＋コードで動き（§9）。ComfyUI が使えなければドット絵 |
| プレイ人数 | 1〜4人（ソロ / オンライン協力・参加コード） |
| 1ステージの長さ | 3〜5分 |
| ペンギンの数 | 20種類（★1〜★3。§5） |
| ステージ | 3ワールド×3ステージ＝9ステージ。各ワールドの最後に大ボス（§6） |
| プラットフォーム | Android / Windows / ブラウザ（WebGL）。横画面固定 |
| 操作 | タッチ・キーボード・コントローラー（§3） |

### 1.1 権利まわりの方針

遊び方はポケモン乱戦スクランブルを参考にするが、キャラクター名・技名・見た目はすべてオリジナルにする。ペンギンは実在の種類を題材にしてよい。

## 2. ゲームの流れ

```text
タイトル
 ├ 冒険（ソロ）  → ワールド・ステージを選ぶ → 編成（3体）→ ステージ → 結果
 ├ 協力（オンライン）→ 部屋を作る / コードで参加 → 編成（各自3体）→ ホストがステージを選ぶ → ステージ → 結果
 ├ ガチャ
 ├ ペンギン一覧（持っている個体・売る）
 └ 設定
```

- 初回起動: 無料ガチャを3回引いて、3体そろえてから始める（§7）
- ソロは「ホストだけで部屋を作った」のと同じ動きにする（通信しないだけ。コードを分けない）

## 3. 操作

| 操作 | スマホ | PC（キーボード） | コントローラー |
| --- | --- | --- | --- |
| 移動 | 左の仮想スティック | WASD / 矢印 | 左スティック / 十字 |
| 技1 | 右のボタン（大） | J | A（南） |
| 技2 | 右のボタン（中） | K | B（東） |
| 必殺技 | 右上のボタン（ゲージ満タンで光る） | L | Y（北） |
| 交代 | 右下の小ボタン | Space | LB |

- 技は向いている方向へ出す。狙いをつける操作は無い（スマホで遊びやすくするため）
- 向きは最後に動いた方向。止まっているときに技を出すと、一番近い敵の方を向く（案）
- 入力は共通基盤の `InputManager`（Input System）・`VirtualJoystick`・`VirtualButton` を使う

## 4. ステージ中のルール

### 4.1 ペンギン3体と交代

- 編成した3体を連れていく。場に出るのは1体
- 交代ボタンを押すと、次の控えと入れ替わる（1→2→3→1 の順で、倒れた子は飛ばす）。交代した後、2秒は交代できない（案）
- HP は1体ずつ。倒れたら、次の控えが自動で出る
- 3体とも倒れたら「ダウン」（§4.5）

### 4.2 技

- 1種類につき技は2つで固定（§5）。技1は短い待ち時間で連打できる技、技2は待ち時間が長い代わりに派手な技
- 技の属性は、そのペンギンの属性と同じ
- 技は「形」を組み合わせて作る（20種類×2＝40個の技を、少ない数のコードで作るため）

| 形 | 動き | 例 |
| --- | --- | --- |
| 近接（Melee） | 前方の扇形にすぐ当たる | パンチ・ビンタ |
| 突進（Dash） | 前へすべり、ぶつかった敵を吹っ飛ばす | 腹すべり |
| 弾（Projectile） | 前へ飛ぶ。貫通するかどうかは技ごと | 水てっぽう |
| 拡散（Spread） | 弾を扇形に複数発 | つらら3本 |
| 周囲（Nova） | 自分の周りに円形で当たる | ボディプレス |
| 設置（Zone） | 前方にしばらく残る範囲。中の敵に少しずつダメージ | うず潮 |
| 落下（Drop） | 近くの敵の頭上に遅れて落ちる | 落雷 |

- 技ごとの数値: 威力・待ち時間・範囲・吹っ飛ばす強さ（技の定義表に持つ）

### 4.3 必殺技

- 敵にダメージを与えるとゲージがたまる。満タンで必殺技ボタンが光る
- ゲージはプレイヤーごとに1本（交代しても引き継ぐ）
- 必殺技は属性ごとに1種類（4種類）。出すときは、ペンギンの顔のカットイン（0.6秒）・画面の揺れ・ヒットストップ
  - 氷: 画面全体の敵が凍って、少しして砕ける
  - 水: 画面の端から大波が流れて、敵を押し流す
  - 風: 自分を中心に大竜巻が起き、敵を巻き上げて飛ばす
  - 雷: 画面中に雷が何本も落ちる
- 必殺技のあいだ、出した本人は無敵

### 4.4 吹っ飛びと連鎖

- 技には「吹っ飛ばす強さ」がある。強く飛ばされた敵は、ほかの敵に当たるとその敵にダメージを与え、その敵も飛ばす（ピンボールのように連鎖する）
- 連鎖のダメージは、ぶつかった速さに比例する（案）
- 壁に当たると跳ね返る
- 当たり判定は円同士で、Unity の物理は使わず純C#で計算する（ホストの計算をそのまま送ればよく、テストも書けるため）

### 4.5 ダウンと復活

- 3体とも倒れたら、その場に「ダウン」の状態で残る（動けない）
- 協力: 仲間がダウンした人の近く（半径1.5マス。案）に合計3秒いると復活する。HP 30% の先頭の子で起き上がる（案）
- 全員がダウンしたらステージ失敗
- ソロ: ダウンしたらステージ失敗

### 4.6 合体技（協力）

- 別のプレイヤーの技が、同じ敵に1秒以内に当たると、自動で合体技が起きる（その敵の位置で）
- 合体技の種類は、2つの属性の組み合わせで決まる（案）

| 組み合わせ | 合体技 | 効果 |
| --- | --- | --- |
| 氷＋水 | 凍結 | 範囲の敵を2秒凍らせる（動けない） |
| 氷＋風 | 吹雪 | 範囲に3秒、少しずつダメージを与えて足を遅くする |
| 氷＋雷 | 氷晶爆発 | 氷が砕けて周りへ破片が飛び散る |
| 水＋風 | うず潮 | 範囲の敵を中心へ吸い込む |
| 水＋雷 | 感電 | 近くの敵へ電気が連鎖する（最大5体） |
| 風＋雷 | 雷雲 | 雷雲がしばらく敵を追いかけて雷を落とす |
| 同じ属性 | 大ばくはつ | 範囲ダメージ＋強い吹っ飛ばし |

- 同じ敵では、1回起きたら2秒は起きない（連続で起き続けないため。案）
- 起きたときは「合体！○○」の文字・大きめのエフェクト・画面の揺れ
- ソロでは起きない（合体技は協力だけの楽しみにする）

### 4.7 敵

- 雑魚: 野生のペンギン。20種類の絵を暗い色にして使い回す。技は技1だけを使う（案）
- ボス: 各ワールドの最後に、ペンギンの天敵（§6）
- 協力の人数で敵を強くする: 敵の HP を 1人×1.0 / 2人×1.6 / 3人×2.2 / 4人×2.8（案）

## 5. ペンギン

### 5.1 数値

- 種類ごとの値: 属性・★・HP の倍率・攻撃の倍率・移動の速さ・技2つ
- 個体ごとの値: **パワー**（ガチャで引いたときに決まる。§7）
- HP ＝ HP の倍率 × パワー、技のダメージ ＝ 技の威力 × 攻撃の倍率 × パワー / 100（案）
- レベル上げは無い。強い個体を引いて強くなる

### 5.2 属性

氷・水・風・雷の4つ（案）。属性による有利・不利の倍率は無い。属性は、合体技の種類（§4.6）と必殺技（§4.3）を決めるだけ。

## 6. ステージ

### 6.1 ステージの形

- 横に長いマップを「エリア」に分ける。1ステージは5エリア＋ボスエリア（案）
- エリアに入ると出入口が閉じ、敵が2〜3回に分けて出てくる。全部倒すと開いて、次のエリアへ進める
- 各ステージの最後のエリアに、そのステージのボス（強い野生ペンギン）。ワールドの3ステージ目は大ボス

### 6.2 ワールド（案）

| ワールド | 背景 | 大ボス（天敵） | 大ボスの攻撃 |
| --- | --- | --- | --- |
| 1 海岸 | 砂浜と流氷 | オオトウゾクカモメ | 空から急降下・羽を飛ばす |
| 2 氷山 | 氷の洞くつ | ヒョウアザラシ | 体当たり・氷の下から飛び出す |
| 3 深海 | 夜の海・氷の割れ目 | シャチ | 波を起こす・画面を横切る突進 |

- ボスの攻撃は、出る少し前に地面へ赤い範囲を出して知らせる（よけられるようにするため）

### 6.3 結果

- クリア: コイン（§7）。協力では全員がもらえる
- 失敗: 倒した敵の数に応じて少しだけコイン（案）
- 協力でホストが選べるのは、ホストが解放したステージ。クリアすると、参加者全員の記録に「クリア済み」が付き、次のステージが解放される

## 7. ガチャ・コイン・コレクション

- コイン: ステージクリアで約100（初めてのクリアは＋100。案）
- ガチャ: 1回100コイン（案）。初回起動時だけ無料で3回
- ★の出る確率: ★1 70% / ★2 25% / ★3 5%（案）
- パワー: 引いたときに範囲内でランダム。範囲は、解放したワールドが多いほど上がる（案）
  - ワールド1まで: 80〜120 / ワールド2まで: 160〜240 / ワールド3まで: 280〜400
  - ★2 は ×1.2、★3 は ×1.5
- 同じ種類がかぶったら、別の個体として増える
- 持てるのは100体まで（案）。いらない個体はコインに換えられる（★1: 10 / ★2: 30 / ★3: 100。案）
- 編成で選んでいる3体は換えられない

## 8. オンライン

- 共通基盤の `OnlineSession`（Unity Relay・参加コード・最大4人）を使う。ブラウザでもつながるように、通信は WebSocket
- **ホストがすべて計算する**: ゲストは入力（移動の向き・押したボタン）だけを送る。ホストは純C#のステージ計算を進めて、全員の位置・HP・起きたこと（技・合体・撃破）を毎秒20回送る（案）
- ゲストの画面は、届いた位置の間を補間して描く
- 遅れが気になったら、自分の移動だけ手元で先に動かす（後で判断。未定）
- 編成: ゲストは参加時に自分の3体（種類・パワー）をホストへ送る
- 切断: ゲストが落ちたら、そのプレイヤーは消える（残りで続ける）。ホストが落ちたら全員タイトルへ戻る（案）
- 報酬は各自の端末で保存する（ホストから「クリアした」と届いたら、自分の記録に書く）

## 9. 見た目と演出

- 斜め見下ろし。奥（画面上）にいるものほど後ろに描く
- ペンギンは斜め前を向いた1枚絵（左右は反転で使う）。動きはコードでつける: 歩くと上下に跳ねる・技でつぶれて伸びる・被弾で白く光って揺れる・倒れると回りながら飛んで消える
- 雑魚の敵は、同じ絵を暗い色にして表示する
- 気持ちよさの演出: ヒットストップ（強い技・必殺・合体）、画面の揺れ、ダメージ数字、撃破時のコインと星のパーティクル
- 音: ペンモンと同じく、BGM は楽譜からコードで作るチップチューン（`GameMusic.Synth` を移植）。素材がそろったら差し替える
- 絵の作り方: Comfy Desktop で、共通のプロンプトと種（seed）を決めて作る。背景を透過して取り込む
  - この PC の GPU は Intel Arc 130T（内蔵）なので、1枚ずつ時間をかけて作る。動かなければドット絵に切り替える

## 10. セーブ

- PlayerPrefs に JSON で保存（キー: `PenguinScramble.Save`。案）。データのバージョンを入れる
- 保存するもの: コイン・持っている個体（固有ID・種類・パワー）・編成の3体・クリア済みのステージ・無料ガチャを使ったか
- ガチャを引いた直後・ステージの結果の後・売った後に保存する
- 読めない記録は消さずに別のキーへ退避する（CLAUDE.md §3.5）
