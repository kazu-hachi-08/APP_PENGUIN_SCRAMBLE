# 実装計画: ステージを3Dにする（ペンギンをコードで組む）

> 仕様は `PENMON_SCRAMBLE_SPEC.md`。各フェーズの終わりに「遊べる状態」にする。
> AI で作った1枚絵のペンギンは「絵が動いているだけ」に見えるので、ペンギン・大ボスを3Dにし、ステージも3Dで描く。
> 形（球・カプセルなど）と動きはすべてコードと定義表から作る（シーン・データをコードで生成する方針のまま）。

## 方針

- **ゲームのルール（Core・純C#）は変えない。** 座標は今までどおり2D（x が右、y が奥）。3D では Core の (x, y) を床の (x, 0, y) に置くだけにする
- **オンラインは変えない。** スナップショット（`StageSnapshot` / `StageCodec`）はそのままで、描き方だけが変わる
- **セーブデータは変えない。** 保存の項目には触らない
- **見た目は「おもちゃのペンギン」。** タイトルのキービジュアルとそろえる。トゥーン調の陰影＋床に落ちる影
- **見た目の良し悪しは人が決める。** フェーズごとにスクショを撮って確認してから次へ進む
- 画面の UI（HUD・タッチボタン・メニュー）は今の Canvas のまま

## 全体

| フェーズ | 遊べるようになること |
| --- | --- |
| 0 | 試作の場で、3Dのペンギン1体が歩く・技を出す・被弾する（見た目の方向性を決める） |
| 1 | 20種類のペンギンを定義表から組み立てられる |
| 2 | ペンギンの動き（歩く・技・被弾・吹っ飛び・ダウン・撃破）がそろう |
| 3 | ステージ全体が3Dで遊べる（カメラ・床・技の見た目・数字） |
| 4 | 状態の見た目（凍る・無敵・突進の残像・敵は暗く・席の輪・復活）が3Dでそろう |
| 5 | 大ボス3体（カモメ・アザラシ・シャチ）が3Dになる |
| 6 | 一覧・ガチャ・カットインの顔が、3Dのペンギンを撮った絵になる |
| 7 | スマホ・ブラウザで重くない。3つの環境でビルドして確かめる |
| 8 | 古い2Dの描き方を消して、仕様書を書き直す |

## フェーズ0: 1体だけの試作

- [x] 描画の設定を確かめる。調べると URP の設定ファイルが無く、実際は Built-in で描かれていた。`Tools/PenmonScramble/Setup URP`（`RenderPipelineSetup`）で URP の Universal Renderer（Forward）の設定を作り、画質 Mobile / PC に割り当てた（`Settings/`）。2Dの見た目（スプライト・UI）は崩れていない
- [x] トゥーン調のシェーダー `Shaders/Toon.shader`（明るい・影の2段＋小さなつや・縁を少し明るく・縁の暗い線。線は `_OutlineWidth = 0` で消える）。足元の丸い影は `Shaders/BlobShadow.shader`

- [x] ペンギン1体を球・卵形で組む（`PenguinModelBuilder`）: 胴・白いお腹・顔・目・くちばし・ヒレ2枚・足2本・頭の寝ぐせ。形は `ToyMeshes` で1つずつ作って使い回す
- [x] 仮の動き（`PenguinMotion`）: 歩く（左右に揺れて足を交互に出す）・技（かがんでから前に出る）・被弾（のけぞって震える）。Play 中は WASD で歩く・J 技・K 被弾・T 影・O 線・C カメラ
- [x] スクショ `Tools/PenmonScramble/3D Preview Capture` → `Screenshots/Preview3D/`（poses.png: 姿勢 × 影と線の組み合わせ、area.png: カメラ4種 × 本物の影 / 丸い影）
- [x] スクショを見て決めた（2026-10-29）
  - カメラ: **透視・見下ろし 55°・画角 30°**。エリア全体（奥のペンギンの頭まで）が収まる距離に置き、上下の真ん中にそろえる（`AreaCameraFit`・`PreviewCameraPresets.Chosen`）
  - 影: **全部の環境で足元の丸い影**。エリア全体で見ると本物の影はぼやけた汚れにしか見えず、丸い影のほうが立ち位置が分かりやすく軽い。URP の本物の影の設定はフェーズ7で切るか決める
  - 縁の線: **あり**（線が無いと黒い背中が床の模様に埋もれる）
  - 体型・色: 今の標準の体型・色（`PenguinLook.Default`）でよい

**決めること**:
- カメラは透視（奥が小さく見えて立体感が出る）か、平行投影（エリアの端まで同じ大きさで見やすい）か。まずは透視で、エリア全体が画面に収まる角度を探す
- 影は、足元に丸い影を置く（軽い）か、本物の影を落とす（重い）か。スマホ・ブラウザは丸い影、PC だけ本物の影でもよい

**完了の確認**: 試作の場で1体が動くスクショを見て、「この方向でよい」と決まる。

## フェーズ1: 20種類を定義表から組む

- [x] 見た目の定義表 `PenguinLooks`（Game 側。Core の `SpeciesTable` とは分ける。見た目だけの値なので）

  - 体型: 太さ・背の高さ・頭の大きさ。目の形（丸・細い・眠そうな線）
  - 飾り（`OrnamentKind`）: 題材のペンギンの模様（アイリング・あごのひも・胸の帯・耳の模様・冠羽）と個性（王冠・メガネ・探検帽・太鼓・杖・雷雲 など）。属性（§5.2）は飾りの色で分かるようにした（氷は水色・水は青・風は緑と黄色の冠羽・雷は黄色）

## フェーズ2: 動きをそろえる

- [x] 動き役 `PenguinMotion`（ペンギンの部品を動かすだけのコンポーネント）。状態は外（フェーズ3で `UnitView`）から受け取る: `Velocity`・`Facing`・`Sliding`（突進）・`Down`（ダウン）と、`PlayAttack(形)`・`PlaySpecial`・`PlayHit`・`PlayKnockback(初速)`・`PlayDefeat`（終わったら `IsDefeatFinished`）
  - 姿勢は `PenguinPose` だけから決まる（`Apply`）。`Tick(dt)` で時刻を進めるので、スクショも同じ流れで撮れる
  - 体全体を動かす土台 `PenguinModel.Figure`（胴と足）を足した。根元の位置・回転・大きさは呼び出し側のまま。足元の丸い影は床に残し、跳ぶと小さく・倒れると前後に伸びる
  - 立っている: ゆっくり呼吸（体が少し伸び縮み）、2〜5秒ごとにまばたき（ひとみを縦につぶす）
  - 歩く: 体を左右に揺らす・足を交互に出す・ヒレを少し開く。速く歩くほど揺れも速い
  - 向き: 進む向きへなめらかに回る（今の左右反転の代わり）
  - 技: かがむ（予備動作）→ 出す → 戻る。形（§4.2）ごとの動きは `PenguinMotion.AttackStyles.cs` の表: 近接は体をひねって右のヒレで払う・弾は振りかぶって投げる・突進は深くかがんで飛び出す（そのあとお腹ですべる）・拡散はヒレを交差させてから大きく開く・周囲はヒレを広げて1回転・設置は跳んで踏みしめ前の床を指す・落下はヒレを空へ上げてから振り下ろす（「回復」という形は Core に無いので作っていない）
  - 必殺技・合体技: 大きくかがんでから跳んで1回転、空中でヒレを上げ、着地でつぶれる
  - 被弾: のけぞる＋震える
  - 吹っ飛び: 飛ばしてきた側へ向き直り、後ろへ転がりながら弧を描いて飛ぶ（物理演算は使わない）。時間と転がる回数は初速と Core の減速（`Balance.KnockbackDeceleration`）から決める。弱いとのけぞってすべるだけ
  - ダウン: お腹を下にして倒れ、顔を上げてヒレを左右交互にじたばた・足もばたつかせる
  - 撃破: 後ろへのけぞりながら回って昇り、後半で小さくなって消える
- [x] 動きの数値（揺れの角度・速さ・時間）は `PenguinMotion` の定数（`PenguinMotion.cs` / `.Parts.cs` / `.Figure.cs` / `.AttackStyles.cs`）にまとめた
- [x] 試作の場: Play 中に 1〜7 で技の形・L 必殺技・K 被弾・B / G 吹っ飛び（強・弱）・X ダウン・V 撃破・Shift+移動 ですべる。P で全部の動きを順に再生（`PenguinMotionDemo`）。ほかのペンギンは半分が歩き、半分がその場で動きを順にくり返す
- [x] スクショ `Tools/PenmonScramble/3D Preview Motion Capture` → `Screenshots/Preview3D/motions.png`（縦に動き、横に始めから終わりまでを6枚）
- [x] テスト `PenguinMotionTests`: どの動きの後も立った姿勢に戻る・どの動きでも床にめり込まない・倒れるとお腹が床に着く・吹っ飛びで転がって立って終わる・撃破で消える・向きはなめらかに回る・まばたきで目が閉じて開く
- [ ] スクショ（motions.png）と試作の場で、動きを確かめる

**完了の確認**: 試作の場で、全部の動きを順に再生してスクショ（または録画）で確かめる。

## フェーズ3: ステージを3Dにする

- [x] 座標の変換: Core の (x, y) → 3D の (x, 高さ, y)。`CoreConversions.ToFloor`
- [x] カメラ: 透視・見下ろし 55°・画角 30°（フェーズ0で決めた構え）。土台（`StageCamera`。横にだけ動く）→ 腕（エリア 16×9 と奥の頭の高さが収まる位置。画面の縦横比が変わると構え直す）→ カメラ（`CameraShake`）の3段。エリアへの移動と揺れは今の仕組みのまま
- [x] 床: 地面の絵（`World1〜3.png`）をトゥーンの床の板に貼る。1つおきに暗く・ボスエリアは赤っぽく・エリアの外は暗く（`StageTheme` のまま）。エリアの境目の門は床に置いた低い柵。太陽（左上の奥から）を1つ置き、光の影は切る（足元の丸い影）
- [x] `UnitView` を3Dのペンギンに差し替えた（`PenguinLooks` から組み、当たりの円と胴の太さをそろえる）。補間（1/30秒ごとの位置の間を描く）はそのまま。動き（`PenguinMotion`）へ渡すもの: 速度（位置の差 ÷ 前の更新からの時間）・向き・突進・ダウン・技（`SkillUsedEvent` の形）・必殺技・被弾・撃破
  - 吹っ飛び: Core の速度はスナップショットに無いので、当たった直後に歩くより速く（6マス/秒〜）動いていたら吹っ飛びとみなし、間の減速を足した初速で `PlayKnockback`
  - 交代したら組み直す。もぐっている大ボスは体を隠して丸い影だけ見せる
  - 足元の席の色の輪と、ダウン中の復活の範囲・たまり具合は、床に寝かせて今のまま出す（`UnitView.Parts.cs`）
- [x] 前後の重なりは3Dの奥行きで決まる。`SortingDepth` は半透明の演出どうしの順番（床の範囲 → はじける演出・光 → 文字）だけにした
- [x] 技の見た目（`StageView.Effects` / `BurstFx` / `EffectView` / `WarningView`）
  - 床に出すもの（設置の円・落下の予告・大ボスの赤い予告・近接のはじける丸）: 床に寝かせた板（`FloorDecal`）
  - 周囲の輪: 床に寝かせた輪が広がる＋足して光らせる光。合体技: 床の輪と光＋胸の高さに浮かべた光
  - 弾（`ProjectileView`）: 属性の色の小さな球のまわりが光り、床に丸い影。敵の弾は暗い色で光も弱い
  - 演出用のシェーダー `Shaders/Fx.shader`（光の当たらない半透明。ふつう / 足して光る / いつも手前）。素材は `StageMaterials` で3つだけ持って使い回す
- [x] 頭の上の「P1」「BOSS」・ダメージ数字（`DamagePopup`）: いつもカメラの方を向き（`FaceCamera`）、ほかの物に隠れない（`BillboardText`）
- [x] 撃破時のコインと星（`DefeatSparkle`）: 上へはじけて弧を描いて落ち、床で1回はねて小さくなって消える。ボスは多く広く。星の形は `ToyMeshes.Star`
- [x] スクショ `Tools/PenmonScramble/3D Stage Capture`（Rebuild → Play → 台本どおりに戦わせて撮る → Play 終了）→ `Screenshots/Stage3D/`（stage1_1〜5: ワールド1を2人で、stage4_1・stage7_1: ワールド2・3の床）。バッチモードは `-executeMethod PenmonScramble.Editor.StageCapture.RunBatch`
- [x] テスト `Stage3DTests`: 床への置き方・カメラにエリア全体と奥の頭が入る（16:9・21:9・4:3）・奥が画面の上・床に寝かせる向き・星の面が外向き・プレイヤーの目印（文字は頭の上・ダウンで復活の範囲）・敵に目印が無い
- [ ] ソロとオンライン（ホスト＋ゲスト）で1ステージを通して遊んで、操作感を確かめる

**完了の確認**: ソロとオンライン（ホスト＋ゲスト）で1ステージを通して遊べる。2Dのときと同じ操作感（入力の向き・当たりの見た目の大きさ）になっている。

## フェーズ4: 状態の見た目

- [x] 色の変え方 `PenguinTint`（元の色を暗くしてから、目当ての色へ寄せる）。`PenguinModel.SetTint` で部品の素材を色ごとの素材に差し替える（素材は状態の数だけ増えるが、SRP Batcher でまとめて描けるまま）。どの色にするかは `UnitView.Status.cs`
- [x] 敵（野生のペンギン）: 同じ形を暗い色で（暗さ 0.45。トゥーンの影の段でさらに暗くなるので 2D の 0.55 より浅い）。大ボスは暗くしない
- [x] プレイヤー: 足元に席の色の輪（床に寝かせる。フェーズ3で済み）
- [x] 凍る: 水色にする＋半透明の氷の塊（`IceBlock`・`ToyMeshes.IceChunk`。トゥーンを半透明で描く `ToonMaterials.Ice`）で包み、動き（`PenguinMotion.Frozen`）を止める。凍ったまま飛ばされたら転がらずに塊ごとすべる。溶けると氷が砕けて飛び散る（`IceShatter`）
- [x] 無敵: 点滅（体全体を 12 回/秒で出し入れ。足元の丸い影と輪は残す）
- [x] 突進: 半透明の残像（`AfterimageTrail`）。体全体を複製した写しを使い回し、今の姿勢を写して置いて薄くしていく。止まったままなら重ねて置かない
- [x] 交代: 白い煙がぽんと出て（`SmokePuff`）、新しい子は小さく出てから弾んで元の大きさになる（`ToyEasing.Pop`）。ダウン・起き上がりも同じ煙
- [x] ダウン: 灰色で倒れている（2D より強く灰色へ寄せる）＋足元に復活の範囲とたまり具合（§4.5。フェーズ3で済み）
- [x] 被弾: 一瞬（0.1秒）白く光る。凍っている間はのけぞらない
- [x] スクショ `Tools/PenmonScramble/3D Stage Capture` の最後に状態の場面を足した → `Screenshots/Stage3D/status1_1〜4`（1: 突進の残像・P2 のダウン、2: 凍る・敵の暗さ、3: 交代の煙、4: 氷が砕ける・被弾の光）。スナップショットの状態を書き換えて起こす（Core は変えない）
- [x] テスト `UnitStatusTests`（敵は暗い・被弾で白く光って戻る・凍ると水色と氷と止まる・溶けると砕ける・ダウンは灰色・無敵は点滅・突進の残像が出て消える・交代の煙と弾み・氷の塊の面が外向き）、`PenguinMotionTests.Frozen_HoldsThePoseUntilThawed`
- [ ] 1ステージの中で全部の状態を見て、2Dのときと同じ情報が読み取れるか確かめる
