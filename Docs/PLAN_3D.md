# 実装計画: ステージを3Dにする（ペンギンをコードで組む）

> 仕様は `PENMON_SCRAMBLE_SPEC.md`。各フェーズの終わりに「遊べる状態」にする。
> AI で作った1枚絵のペンギンは「絵が動いているだけ」に見えるので、ペンギン・大ボスを3Dにし、ステージも3Dで描く。
> 形（球・カプセルなど）と動きはすべてコードと定義表から作る（シーン・データをコードで生成する方針のまま）。

## 方針

- **ゲームのルール（Core・純C#）は変えない。** 座標は今までどおり2D（x が右、y が奥）。3D では Core の (x, y) を床の (x, 0, y) に置くだけにする
- **オンラインは変えない。** スナップショット（`StageSnapshot` / `StageCodec`）はそのままで、描き方だけが変わる
- **セーブデータは変えない。** 保存の項目には触らない
- **見た目は「おもちゃのペンギン」。** タイトルのキービジュアルとそろえる。トゥーン調の陰影＋床に落ちる影
- **見た目の良し悪しは人が決める。** フェーズごとにスクショを撮って確認してから次へ進む
- 画面の UI（HUD・タッチボタン・メニュー）は今の Canvas のまま

## 全体

| フェーズ | 遊べるようになること |
| --- | --- |
| 0 | 試作の場で、3Dのペンギン1体が歩く・技を出す・被弾する（見た目の方向性を決める） |
| 1 | 20種類のペンギンを定義表から組み立てられる |
| 2 | ペンギンの動き（歩く・技・被弾・吹っ飛び・ダウン・撃破）がそろう |
| 3 | ステージ全体が3Dで遊べる（カメラ・床・技の見た目・数字） |
| 4 | 状態の見た目（凍る・無敵・突進の残像・敵は暗く・席の輪・復活）が3Dでそろう |
| 5 | 大ボス3体（カモメ・アザラシ・シャチ）が3Dになる |
| 6 | 一覧・ガチャ・カットインの顔が、3Dのペンギンを撮った絵になる |
| 7 | スマホ・ブラウザで重くない。3つの環境でビルドして確かめる |
| 8 | 古い2Dの描き方を消して、仕様書を書き直す |

## フェーズ0: 1体だけの試作

- [ ] 描画の設定を確かめる。URP の 2D Renderer だと3Dの物体に光が当たらないので、Universal Renderer（Forward）に切り替える。今の2Dの見た目（スプライト・UI）が崩れていないか確かめる
- [ ] トゥーン調のシェーダーを1つ作る（2〜3段の陰影＋縁の暗い線は任意）。URP の Lit でよければそれでもよい
- [ ] 試作の場を Editor メニューで作る（`Tools/PenmonScramble/3D Preview`）。床・斜め上からのカメラ・光を置く
- [ ] ペンギン1体を球・カプセルで組む: 胴・白いお腹・目・くちばし・ヒレ2枚・足2本
- [ ] 仮の動き: 歩くと左右に揺れて足を交互に出す、技でかがんでから前に出る、被弾でのけぞる
- [ ] スクショを撮って見た目を決める（体型・色の濃さ・カメラの角度・影の出し方）

**決めること**:
- カメラは透視（奥が小さく見えて立体感が出る）か、平行投影（エリアの端まで同じ大きさで見やすい）か。まずは透視で、エリア全体が画面に収まる角度を探す
- 影は、足元に丸い影を置く（軽い）か、本物の影を落とす（重い）か。スマホ・ブラウザは丸い影、PC だけ本物の影でもよい

**完了の確認**: 試作の場で1体が動くスクショを見て、「この方向でよい」と決まる。

## フェーズ1: 20種類を定義表から組む

- [ ] 見た目の定義表 `PenguinLooks`（Game 側。Core の `SpeciesTable` とは分ける。見た目だけの値なので）
  - 色: 背中・お腹・くちばし・足・目のまわり
  - 体型: 太さ・背の高さ・頭の大きさ
  - 飾り: 冠羽（イワトビ）・王冠・眉・とさか・氷のトゲ・ほのおの毛 など。属性（§5.2）が分かる飾りにする
- [ ] 組み立て役 `PenguinModelBuilder`: 定義から部品の階層を作る。メッシュは形ごとに1つ作って使い回す（球・カプセル・円錐）。当たり判定（Collider）は付けない（ゲームの当たりは Core が持つ）
- [ ] 試作の場に20体を並べて表示するメニューを足す（並べてスクショで見比べる）
- [ ] テスト: 定義表に20種類がそろっているか

**完了の確認**: 20体を並べたスクショで、どれがどの種類か見分けられる。

## フェーズ2: 動きをそろえる

- [ ] 動き役 `PenguinMotion`（ペンギンの部品を動かすだけのコンポーネント）。状態は `UnitView` から受け取る
  - 立っている: ゆっくり呼吸（体が少し伸び縮み）、ときどきまばたき
  - 歩く: 体を左右に揺らす・足を交互に出す・ヒレを少し開く。速さに合わせて揺れを速くする
  - 向き: 進む向きへなめらかに回る（今の左右反転の代わり）
  - 技: かがむ（予備動作）→ 前へ伸びる・ヒレを振る。技の形（近接・弾・周囲・設置・落下・突進・回復 §4.2）ごとに少し変える
  - 必殺技・合体技: 大きくかがんでから跳ぶ・回る
  - 被弾: のけぞる＋震える
  - 吹っ飛び: 転がって飛ぶ（物理演算は使わず、コードで決めた回転）
  - ダウン: お腹を下にして倒れて、ヒレをじたばた
  - 撃破: 回りながら飛んで消える（今の動きを3Dにする）
- [ ] 動きの数値（揺れの角度・速さ・時間）は `PenguinMotion` の定数にまとめる

**完了の確認**: 試作の場で、全部の動きを順に再生してスクショ（または録画）で確かめる。

## フェーズ3: ステージを3Dにする

- [ ] 座標の変換: Core の (x, y) → 3D の (x, 0, y)。`CoreConversions` に置く
- [ ] カメラ: 斜め上から見下ろす。エリア（16×9マス）が画面に収まるようにする。エリアへの移動（`StageCamera`）と揺れ（`CameraShake`）は今の仕組みのまま
- [ ] 床: 地面の絵（`World1〜3.png`）を床の板に貼る。1つおきに暗く・ボスエリアは赤っぽく・エリアの外は暗く（今の `StageView.Ground` と同じルール）。エリアの境目の門も床に置く
- [ ] `UnitView` を3Dのペンギンに差し替える。補間（1/30秒ごとの位置の間を描く）はそのまま
- [ ] 前後の重なりは3Dの奥行きで決まるので、ユニットには `SortingDepth` を使わない
- [ ] 技の見た目（`StageView.Effects` / `BurstFx` / `EffectView` / `WarningView`）
  - 床に出すもの（設置の円・落下の予告・大ボスの赤い予告・近接のはじける丸）: 床に寝かせた板
  - 周囲の輪・合体技の光: 床に寝かせた輪が広がる＋光
  - 弾（`ProjectileView`）: 属性の色の小さな球が光る。敵の弾は暗い色
- [ ] 頭の上の「P1」「BOSS」・ダメージ数字（`DamagePopup`）: いつもカメラの方を向き、ほかの物に隠れないようにする
- [ ] 撃破時のコインと星: 3Dで飛び散る

**完了の確認**: ソロとオンライン（ホスト＋ゲスト）で1ステージを通して遊べる。2Dのときと同じ操作感（入力の向き・当たりの見た目の大きさ）になっている。

## フェーズ4: 状態の見た目

- [ ] 敵（野生のペンギン）: 同じ形を暗い色で（色に暗さを掛ける）
- [ ] プレイヤー: 足元に席の色の輪（床に寝かせる）
- [ ] 凍る: 水色にする＋氷の塊で包む
- [ ] 無敵: 点滅
- [ ] 突進: 半透明の残像（形を写したものを置いて薄くしていく）
- [ ] 交代: ぽんと煙が出て入れ替わる
- [ ] ダウン: 灰色で倒れている＋足元に復活の範囲とたまり具合（§4.5）
- [ ] 被弾: 一瞬白く光る（3Dなら白くできる。今の赤っぽくする代わり）

**完了の確認**: 全部の状態を1ステージの中で見て、2Dのときと同じ情報が読み取れる。

## フェーズ5: 大ボス3体

- [ ] 大ボスごとに組み立て役を作る（形がペンギンと違うため）: カモメ（翼で羽ばたく）・アザラシ（体をくねらせて這う）・シャチ（もぐる・跳び出す）
- [ ] 大ボスの技・もぐり（§6.2）に合わせた動き。もぐっている間は床に暗い影だけ見せる
- [ ] ステージのボス（大きい野生のペンギン）は、ペンギンを大きくして使う（今と同じ）

**完了の確認**: 3つのワールドの大ボス戦を通して遊べる。

## フェーズ6: UI の顔を3Dから作る

- [ ] Rebuild のときに、20種類と大ボス3体を撮影して PNG にする（Editor スクリプト。少し斜め前から、背景は透過）。`CreatureArt` はその絵を使う
- [ ] 一覧・ガチャ・必殺技のカットインの顔が、ゲーム中の見た目と一致しているか確かめる
- [ ] タイトルの背景（AI のキービジュアル）はそのまま使う。合わなければ、3Dのペンギンを並べて撮った絵に替えるかを決める

**完了の確認**: 一覧・ガチャ・カットインの顔が、ゲーム中のペンギンと同じに見える。

## フェーズ7: 重さとビルド

- [ ] 一番敵が多いステージで、4人のときの重さを測る（スマホ・ブラウザ・PC）。目標は PC 60fps、スマホ・ブラウザ 30fps 以上
- [ ] 重いときの対策: 部品を減らす（遠い敵は簡単な形）・面を減らす・同じ素材をまとめて描く（SRP Batcher / GPU インスタンシング）・本物の影を切る
- [ ] 画質の設定（Mobile / PC）ごとに、影・縁の線のありなしを分ける
- [ ] Android / Windows / WebGL でビルドして起動する

**完了の確認**: 3つの環境で1ステージを通して、カクつかずに遊べる。
