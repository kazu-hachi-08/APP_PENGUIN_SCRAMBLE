## 0. 決まったこと（まとめ）

| 項目 | 決定 |
| --- | --- |
| 遊びの形 | **おもちゃの野球盤**。投げる側は球種を選んで投げ、投げた後に曲げる。打つ側はタイミングでバットを振るだけ（カーソルは無し）。今の斜め見下ろし・おもちゃの3Dの見た目のまま |
| 打球の結果 | **打球は盤の上を本当に転がる**。アウトの穴・ヒットの穴に入るか、止まった場所、フェンスを越えるかで決まる |
| 打球の高さ | **強い当たりだけ浮く**（放物線）。浮いている間は穴に落ちない。フェンスを越えたらホームラン |
| 守備の子 | **穴の後ろに立つ飾り＋演出**。結果は穴だけで決まり、守備の子は捕る・悔しがる動きをする |
| 走者 | **自動で進む**。アウトの穴は「ゴロ」「フライ」「ゲッツー」の3種 |
| 投げる操作 | **球種3種**（ストレート・カーブ・チェンジアップ）を選んで投げ、**投げた後もスティック / ←→ で左右に曲げる** |
| 打つ操作 | **振る**（ボタン1つ。早い＝引っ張り・遅い＝流し・ジャスト＝強い）＋**バント**（もう1つのボタンで構える） |
| ストライク・ボール | **ゾーンあり**。曲げすぎてゾーンを外れたらボール（4つで四球）。打つ人は見送れる（3ストライクで三振） |
| 投げる子 | **打席ごとに**編成の3体から選ぶ。打つ側は編成の 1→2→3 の打順をくり返す |
| 個体差 | **属性ごとの魔球4種（投げる）と必殺打4種（打つ）**。★が高いほど強い。**パワー（育成）は効かせない** |
| 魔球・必殺打の回数 | **各子1試合1回**ずつ（魔球と必殺打は別に数える） |
| 出し方 | 投げる前に**投げる人と打つ人が同時に、相手に見えないまま選ぶ**。投げた瞬間に両方のカットインが出る |
| 試合 | **3イニング**（表裏・3アウトで交代）。**同点なら引き分け** |
| カメラ | **キャッチャーの後ろの高め**から盤のほぼ全体。打球は少し寄って追う。投げる人も同じ画面 |
| コース | **5球場**（ストーリーの5ワールドの景色）。球場ごとに**穴の並び・フェンス・仕掛け・CPU の強さが違う**。ストーリー連動で解放（ゴルフ・サッカーと同じ） |
| ひとり | 自分の3体 対 CPU の3体 |
| オンライン | 最大4人。待ちの窓でホストが **対戦**（赤・青に分ける）か **協力**（全員で CPU と戦う）を選ぶ（サッカーと同じ） |
| 記録 | ベスト＝**1試合の得失点差の最高**（大きいほど良い）。special＝**勝った回数**（引き分けは数えない） |
| 報酬 | **コイン**。出た分＋勝ち（引き分けは少し）＋点。その球場で初めて勝ったらボーナス。本編より控えめ |

| 6 | 球場2〜5と仕掛け | 5球場が遊べる。ストーリー連動で開く。盤・仕掛け・CPU の強さが球場ごとに違う |
| 7 | 仕上げとリリース | 遊び方・音・報酬の調整・仕様書。Windows / ブラウザ / Android で配信 |

2〜4 はひとりで遊べる所まで縦に通す（「投げた後に曲げる × タイミングで振る」の手ごたえがこのゲームの芯なので、2 で早く確かめる）。CPU と試合の数値（打率・点の入り方）は読みにくいので 3 を独立したフェーズにして、試合の確認（自動で何試合も回す）で決める。オンライン（5）は「ひとりで1試合」が固まってから。球場の量産（6）は最後。

> うまくいかなかったときの縮め方: 2 で「投げた後に曲げる」が打つ側に理不尽に感じられたら、曲げられる区間を短くする・曲げを球種の決まった曲がりだけにする、の順で縮める。縮めるときはユーザーに確認する。

## 野球のルール（案の数値はフェーズ 2・3・4・7 で決め直す）

### 盤

- 扇形の盤。手前がホーム、奥が外野のフェンス。左右のファウルラインの外はファウルの溝（転がり込んだらファウル）
- 盤の上の物（コードの定義表 `BaseballFieldDef`）:
  - **アウトの穴**: ゴロ（内野）・ゲッツー（二塁ベースの上。フェーズ 2 で、二塁ベースと重なるので白いベースの真ん中を穴にした）・フライ（外野）。穴の後ろに守備の子が立つ
  - **ヒットの穴**: 単打（内野の間・外野の手前）・二塁打（外野の間）・三塁打（フェンス際の隅）
  - **止まった場所の札**: 穴に入らずに止まったら、止まった所で決める（内野の土＝ゴロアウト、外野の芝＝単打、フェンス際の帯＝二塁打。案）。盤はゆるいすり鉢で、球が盤の上でいつまでも転がらないようにする
  - **フェンス**: 高さを持つ。浮いた球がフェンスより高く越えたらホームラン。低ければ当たって跳ね返り、盤に戻る
  - ストライクのゾーン（ホームの上の幅）・投げる所（マウンド）・バットの軸
- 計算はすべて純C#（Unity の物理は使わない）。1/30 秒の固定の刻み（本編・サッカーと同じ）。数値は `BaseballRules`（ルール）・`BaseballBalance`（球とバット）
- 穴の判定はゴルフのカップと同じ形（穴の上を通るとき、遅ければ落ちる・速すぎると縁で曲がって通り過ぎる）。強い打球ほど穴を越えていくので、「ジャストの強い当たり＝ヒットになりやすい」が自然に出る

### 投げる

1. 打席の始めに、投げる側が**投げる子を3体から選ぶ**（前と同じ子でも良い）
2. 1球ごとに**球種**を選ぶ（＋魔球の ON。各子 1試合1回）。同時に打つ側は必殺打の ON を選ぶ（後述）
3. 投げる（ボタン）。球はマウンドからホームへ盤の上を転がってくる
4. 投げた後、**スティック / ←→ で左右に曲げる**（盤の下の磁石のような手ごたえ）。曲げられるのは**ホームの手前の一定の所まで**（案: 道のりの 70%）。最後の区間はまっすぐ来る（打つ人が読める区間を残すため。オンラインの遅れもこの区間で吸収する）

| 球種 | 速さ（案） | 曲げやすさ（案） |
| --- | --- | --- |
| ストレート | 速い（ホームまで 0.7 秒） | 小さい |
| カーブ | ふつう（1.0 秒） | 大きい |
| チェンジアップ | とても遅い（1.4 秒） | ふつう |

- 1球の持ち時間 8 秒（案）。過ぎたら、そのとき選んでいる球種でまっすぐ投げる
- ホームの線を通るとき、ゾーンの幅の中ならストライク、外ならボール（振っていないとき）

### 打つ

- **振る**（ボタン）: 押した瞬間にバットが軸を中心に回る。バットの回る角度と球の位置で当たりを決める
  - 当たる時が早い＝引っ張り、遅い＝流し（バットの角度で打球の向きが決まる）
  - バットの芯に近いほど強い打球。根元・先は弱い（ボテボテ）
  - ジャスト＆芯の強い当たりだけ浮く（放物線）。浮かない打球は転がる
  - 球の通る所がバットの届かない所（ゾーンの外の遠い所）なら当たらない（空振り）
- **バント**（もう1つのボタン）: 押している間バットを寝かせて構える。当たると弱く転がる（内野の手前で止まりやすい。止まればゴロ扱い＝犠打で走者が進む。ライン際のヒットの穴に入ればバントヒット）
- 振らなければ見送り（ゾーンの中ならストライク、外ならボール）
- ファウル: ファウルの溝に入る・ファウルラインの外へ出る。2ストライク未満ならストライクを1つ足す（2ストライクからは足さない。バントのファウルも同じ）
- 3ストライクで三振、4ボールで四球

### 走者（自動）

| 結果 | 打者 | 走者 |
| --- | --- | --- |
| 単打 / 二塁打 / 三塁打 | その塁へ | 全員その塁の数だけ進む |
| ホームラン | ホームへ | 全員ホームへ |
| 四球 | 一塁へ | 押し出される走者だけ1つ進む |
| ゴロアウト（バントの犠打も） | アウト | 全員1つ進む（その打球で3アウトなら点は入らない） |
| ゲッツー | アウト | 一塁に走者がいて2アウト未満なら一塁の走者もアウト、ほかは1つ進む。それ以外はゴロアウトと同じ |
| フライアウト | アウト | 進まない。三塁の走者だけホームへ（タッチアップ。その打球で3アウトなら入らない） |

- 走者は盤の塁の上におもちゃのコマのように立ち、結果のあとに走る演出（打球が決まってから動く。走っている間に何かを決めることは無い）

### 試合の流れ

1. 3イニング。表は赤（ひとりでは自分が先攻か後攻かを試合ごとに交互。案）、裏は青。3アウトで交代
2. 3回裏で後攻が勝っていれば、その時点で終わり（サヨナラも同じ）
3. 3回が終わって同点なら**引き分け**
4. 点差が大きく開いたら早く終わる（2回終わって 10 点差。案。CPU の強さが段違いのときにだらだら続かないように）
5. 打順は編成の 1→2→3 をくり返す（イニングをまたいで続き）

### 魔球（投げる側）と必殺打（打つ側）

- 各子 1試合1回ずつ。魔球はその子が投げるとき、必殺打はその子が打つときだけ出せる。使った子のカードは暗くなる
- **出し方**: 投げる前に、投げる人は「球種＋魔球の ON」、打つ人は「必殺打の ON」を、**相手に見えないまま同時に**選ぶ。投げた瞬間に両方のカットインが出る（本編と同じペンモンの顔のカットイン。0.6 秒。全員の画面で止める）
- 必殺打は**当たったときだけ使った扱い**（空振り・見送りなら残る。ファウルは使った扱い。案）
- 魔球は投げたら使った扱い（ボールになっても）

| 属性 | 魔球（案） | 動き | ★で変わる所 |
| --- | --- | --- | --- |
| 氷 | フリーズボール | 途中で一瞬凍って止まり、また動き出す（タイミング崩し） | 止まる長さ（★が高いほど長さに幅が出て読みにくい） |
| 水 | ゆらゆらボール | 波のように左右に揺れて進む | 揺れる幅 |
| 風 | 旋風ボール | 曲げる操作が大きく効き、最後に逆へ曲がる | 曲がる大きさ |
| 雷 | 消える魔球 | 途中で消えて、ホームの手前で現れる | 消える距離 |

| 属性 | 必殺打（案） | 打球 | ★で変わる所 |
| --- | --- | --- | --- |
| 氷 | アイスロード | 打球の通り道が凍り、アウトの穴の上を滑って渡る | 凍る長さ |
| 水 | 水切りヒット | 水切りのように跳ねて穴を飛び越える | 跳ねる回数（1 / 2 / 3） |
| 風 | 追い風ヒット | 打った後にスティックで打球を左右に曲げられる | 曲がる大きさ |
| 雷 | イナズマ打ち | とても速い打球。穴の上を通っても落ちず、フェンスを越えやすい | 速さ |

- 魔球の動きと必殺打の当たりやすさの釣り合い（必殺打を ON にしても魔球には当たりにくい、など）はフェーズ 4 の試合の確認で決める

### CPU

- 投げる: 球種・魔球を乱数で選び、曲げ方を数種の型（外へ逃げる・内へ食い込む・まっすぐ）から選ぶ。ゾーンの端を狙う正確さが強さで上がる
- 打つ: 球の来る時刻と位置を読んで振る。読みの**ぶれ（タイミングの誤差）**が強さの一番の差。曲げられた球・魔球ほどぶれが大きい。ゾーンの外の球を見送る賢さも強さで上がる。バントは走者がいて点差が小さいときに少し
- 投げる子・必殺打を出す所は簡単な決まり（ピンチ・チャンスで出しやすい。案）
- CPU の強さ（球場ごと。`BaseballBalance`）は★1〜★5。協力では人数で上乗せ（サッカーと同じく2人目から1人ごとに★+1。案）

### 報酬（案）

- コイン ＝ 出た分 20 ＋ 勝ち 50（引き分けは 20）＋ 自分のチームの点 1 につき 8（5 点まで）
- その球場で初めて勝ったら +100
- オンラインの対戦・協力も同じ式（各自の端末で、自分のチームの結果で計算）
- 本編の1ステージの報酬と比べて控えめになるよう、フェーズ 7 で決め直す（ゴルフ・サッカーに合わせる）

## フェーズ 1: 入口とシーン・計算（Core）と試しの打席

## フェーズ 2: 見た目と操作

### やること

1. 盤の3D: おもちゃの野球盤（ブリキ・木の質感のトゥーン）。内野の土・外野の芝・白い線・塁・フェンス（高さが見える）・穴（ふちの色で種類が分かる。ヒットは明るい色、アウトは暗い色。穴の上に「1B」「アウト」などの小さな札）。景色はワールドの地面の絵を盤のまわりに敷く（サッカーと同じ）
2. 球: おもちゃの白い球と影。浮いた球の影でどこへ落ちるか分かるように
3. 子: `Penguin3D` に投げる（振りかぶる → 投げる）・構える・振る・バントの構え・打った後に走り出す・ホームランで喜ぶ・三振で悔しがるの動き（動きの定義に足す）。守備の子は穴の後ろで構え、球が穴に入ったら捕る
4. 投げる操作: 球種の選び（3つのボタン / キー。タッチは3つの球種の札）→ 投げる → スティック / ←→ / 画面の左右のドラッグで曲げる。曲げられる区間を盤の上に薄く見せる（線の手前まで）
5. 打つ操作: 振る＝J / ×（南）/ 右の大ボタン。バント＝K / ○（東）/ 右の中ボタン（押している間構える）
6. ゾーン: ホームの上の枠（ストライクで光る・ボールで灰色に）
7. カメラ: キャッチャーの後ろの高めから盤のほぼ全体。打球は少し寄って追い、ホームランはフェンスの向こうまで追う。結果が決まったら戻る
8. HUD（仮）: カウント（B・S・O）・結果の大きな文字
9. 音: 投げる・バットに当たる（強さで変える）・空振り・穴に落ちる・フェンスに当たる・ホームランの歓声・ミットの音

- 押しても何も起きないボタンは置かない（魔球・必殺打のボタンはフェーズ 4 で足す）

### 遊べる状態

試しの打席で、本番の見た目と操作で、投げる・曲げる・振る・バントを気持ちよくできる（タッチ・キーボード・コントローラー）。開発用メニューで「自分が投げる側（CPU が打つ）」にも切り替えられる。

### 実装で決めたこと（2026-11-07）

- **球種は押したらそのまま投げる**（選ぶ → 投げるの2回押しにしない）。J / K / L（× ○ △・画面の札）がそれぞれ ストレート / カーブ / チェンジアップ。フェーズ 4 の魔球は「魔球の ON を先に押してから球種を押す」形で足す。持ち時間切れは前に投げた球種でまっすぐ

- カウント（`BaseballCount`）と CPU の最初の形（`BaseballAi`。投げる: 曲げ方の型とねらい、打つ: 区間の終わりで見送り / 振るを決めて、ジャストの時刻＋ぶれで振る）はフェーズ 2 で作った。★ごとの強さ・バント・投げる子の選び方はフェーズ 3
- キャッチャーの子を置いた（ミットの音と捕る動き。投げた球はミットまで運んで消す）

## フェーズ 3: 試合のルールとCPU

### やること

1. 打席（`BaseballAtBat`）: カウント・見送り・空振り・ファウル・三振・四球・打球の結果
2. 走者と点（`BaseballBases`）: 上の表のとおり。テスト（各結果での走者の進み・3アウト目で点が入らない・タッチアップ・ゲッツー・押し出し）
3. 試合の流れ（`BaseballGame`）: 3イニング・表裏の交代・打順の続き・サヨナラ・点差で早く終わる・引き分け。投げる子を打席ごとに選ぶ
4. CPU（`BaseballAi`）: 投げる（球種・曲げ方の型・ゾーンの端の狙い）・打つ（読みのぶれ・見送り・バント）。強さの調整値
5. **試合の確認**（`Tools > PenmonScramble > Baseball > CPUの試合の確認`）: CPU 同士を自動で何試合も戦わせ、1試合の点・打率・ホームラン・三振・四球・穴ごとの入った割合・1試合の時間（球数から）・強さの差で勝ち負けの割合が変わるかを出す（サッカーの試合の確認と同じ考え方。Core の計算だけで速く回す）
6. 確認の結果で、盤の穴の大きさ・並び、止まった場所の札、バットの芯の幅を決める（1試合 3〜6 点くらい・ホームランは1試合 0〜1 本くらいが目安。案）

### 遊べる状態

試しの球場で、自分の3体 対 CPU の3体で、3イニングの試合を最後までできる（バントで走者を進めるのも）。

### 実装で決めたこと（2026-11-07）

- **打席は `BaseballCount` のまま**（`BaseballAtBat` は作らなかった）。走者は `BaseballBases`、試合は `BaseballGame`（カウント・走者・点・打順・投げる子・終わり）。ゲッツーの2つ目のアウトは `BaseballGame` が `Count.AddOut` で足す。3アウト目は `IsHalfOver` で止め、見せ終わってから `StartNextHalf` で攻守を替える（「チェンジ」の前に3アウト目の塁と点を見せるため）
- 試しの打席は `BaseballGame.Practice`（同じチームが打ち続け、3アウトでアウトと走者を戻すだけ）。開発用メニューに **試しの試合（先攻）/（後攻）** を足した。試合の後の「もう一度」は先攻・後攻を入れ替える（ひとりの交互の案）。試しの試合の CPU は ★1
- 点差で早く終わる: **2回裏以降、後攻が 10 点差でリードした時点 / 2回裏・3回の終わりに 10 点差**。3回表が終わって後攻が勝っていたら裏はしない
- 投げる子: 人が守る打席の始めに左の札（↑↓・タッチ）で選ぶ（前の子のまま投げてもよい。魔球の無いうちはどの子も同じ）。CPU はイニングごとに順に替える
- 走者の子は塁の横に立ち、打席の結果のあとに塁を回って走る（ホームランでも 1.8 秒で走り終える速さ）。塁に出た打者は、打席の子から走者の子へ入れ替わる
- HUD（仮）: 上のまん中に「あなた 点 − 点 CPU」・何回の表 / 裏・塁のひし形。ゲームセットは暗い幕に勝ち負けと点・もう一度・もどる（結果と報酬の欄はフェーズ 4）
- **CPU**（`BaseballAi`）: ★ごとのうまさ `BaseballBalance.AiSkill(★)`（振る時刻のぶれ 0.10 / 0.08 / 0.06 / 0.045 / 0.03 秒・ゾーンの外を見送る 45〜85%・狙いのぶれ 0.22〜0.07）。振る時刻のぶれに比例して**通る所の見え方もぶれる**（外の球に手を出して空振り・きわを見逃し）。追い込まれるまではゾーンの中も 3 割見送る（毎回の初球打ちにしない）、追い込まれたらきわをカット。投げる側: 曲げない球は 1 割（ど真ん中が多いとホームランだらけになった）、外す球は 3 割（2ストライクからは 4 割・3ボールでは外さない）で、**外す球はカーブかチェンジアップ**（ストレートは曲がりが小さくゾーンの外へ届かない）。バントは一塁か二塁に走者・2アウト未満・点差 2 点までの打席の 3 割
- **試合の確認**（`Tools > PenmonScramble > Baseball > CPUの試合の確認`。`BaseballMatchCheck`）で決めた数:
  - 最初の盤（転がりの摩擦 5・芯の幅 0.3）では打率 .85・1試合 45 点（強い当たりがほとんど外野の芝で止まって単打になる）。**転がりの摩擦 7**（弱い当たりは内野で止まる）・**芯の幅 0.2**・**浮くのは強さ 0.9 から**・外野の芝の奥の線 12.2 にした
  - 盤: 外野の手前（9.2）にフライの穴 5つ（半径 0.7）、その奥（11.6）の間に二塁打の穴 4つ、三塁打の穴は ±32°・11.2
  - 結果（CPU 同士 200 試合）: 1試合の点 合計 3.3〜4.1・ホームラン 0.6〜1.5 本・打率 .36・三振 0.3〜2.8・1試合 4〜5 分（CPU 同士）。打球の内訳はゴロ 5 割・単打 2.5 割・二塁打 7%・フライ 4〜9%・ホームラン 3〜6%。強さの差: ★1 対 ★5 で 20 勝 160 敗、★2 対 ★3 で 48 勝 123 敗、★3 対 ★4 で 56 勝 113 敗。点が少ないので引き分けが 2 割ほど出る
  - CPU 同士では四球がほとんど出ない（CPU の打者が早いカウントで打つため）。人が見送れば四球は出る

## フェーズ 4: ひとりで1試合（魔球・必殺打・球場1・結果）

### やること

1. 魔球4種・必殺打4種（Core。★で強さ）・各子1試合1回の管理・同時に選ぶ流れ・カットイン・テスト

5. 結果: 勝ち負け・引き分け・点・得失点差・コインの内訳・ベスト更新・初勝利ボーナス・「もう一度」「球場を選ぶ」「ロビーへ」。報酬と記録を書いて保存（`BaseballReward` → `MiniGameReward`）。結果の欄は共通の `MiniGameResultPanel`
6. 試合中のメニュー（‖ / Esc）: つづける・試合をやり直す・設定（音量）・ミニゲーム画面へ（本編の `StageMenu` の見た目を使い回す。遊び方はフェーズ 7）
7. 仕様書 §13.5 を書き始める

### 遊べる状態

ミニゲーム画面から「ひとりで」球場1で3イニングの試合をし、魔球・必殺打を使い、結果でコインとベストがもらえる。

### 実装で決めたこと（2026-11-07）

- **魔球・必殺打の ON は Space / L1（画面の札）**。投げる前に ON にしておき、投げた瞬間に合わせる。魔球の ON は投げたら戻り、必殺打の ON はその打席の間残る（当てるまで使わないので）。打つ番は CPU の構えが短いので、打席が続く間の結果を見せている間にも札を押せる。残っていない子のときは札を出さない
- 魔球の中の乱数（凍る秒・揺れの位相）は投げるときに決めて `BaseballPitchMagic` に持たせる（投げた後の道のりは入力の時刻だけで決まる。フェーズ 5 でゲストへ送るのもこれ）
- **フリーズボールは道のりの 80%（曲げられる区間の後）で凍る**。区間の中で止めると、動き出した後に読み直せてタイミングが崩れなかったため
- **旋風ボールの「最後に逆へ曲がる」は、曲げられる区間の後のまっすぐの区間で曲げる**（決まった速さなので、オンラインでも同じ道のりになる）。消える魔球は見た目だけ（当たりは変わらない）
- 必殺打はバントでは使わない。イナズマ打ちは「速さ 3 より速い間はどの穴にも落ちない」にした（どこまでも落ちないと、当てれば 9 割がヒットになったため）
- 両方がぶつかったときの特別な決まりは作らなかった（必殺打の当たりやすさは変えない。魔球で崩れて当たらなければ必殺打は残る、で釣り合った）
- 試合の確認の結果（CPU 同士 300 試合×組）: 魔球を打ってヒットにされる割合 フリーズ 4〜10%・旋風 5〜7%・ゆらゆら 10〜14%・消える 13〜17%（ふつうの球は 16%）。必殺打は当てれば アイスロード 45〜61%・水切り 42〜49%・追い風 32〜48%（CPU の曲げ方は単純）・イナズマ 46〜68%（ホームラン 6〜12%）がヒット（ふつうの当たりは 30%）。1試合の点は 3.3〜3.9 → 4.0〜4.9 に増え、強さの順に勝ちにくいのは変わらない
- CPU の打つ側: 振る時刻は決めたときに取っておく形にした（凍った球に、待ち直せなければそのまま振ってしまう）。★ごとの「待ち直せる・逆の曲がりを読める」割合（15〜55%）を `BaseballAiSkill.MagicReadChance` に足した
- 球場は `BaseballStadiumTable`（球場1「海岸」だけ。盤は試しの盤と同じ並びの `BaseballFieldTable.Beach`）。CPU の3体はワールド 1 の雑魚の混ぜ方から試合ごとに選ぶ
- **ひとりの先攻・後攻: 最初は自分が先攻**（打つ方から始まる方が分かりやすい）。「もう一度」で入れ替え、「試合をやり直す」は同じまま
- 報酬は計画書の案のまま（20・勝ち 50・引き分け 20・1点 8（5点まで）・初勝利 100）。人が入った1試合 5〜6 分で 1時間に最大 1200 ほど（ゴルフ・サッカーと同じくらい）
- ゲームセットの欄（フェーズ 3 の仮）は消し、共通の結果の欄にした。結果の間はスコアボードを左へ寄せて残す
- メニューの「遊び方」の札はフェーズ 7 まで出さない（遊び方の画面を渡していない）。野球の BGM もフェーズ 7（まだ曲を差し替えていない）

9. 仕様書 §8・§13.5 を直す

### 実装で決めたこと（2026-11-07）

- **チーム分けの共通化**: 対戦 / 協力（`MiniGameOnlineMode`）・赤青の決まり（`MiniGameTeams`）・待ちの窓の選び（`MiniGameRoomChoice`。並びとメッセージの名前はサッカーのまま）・ホストの選びの覚え場所（`MiniGameRoomSetup`。ミニゲームごと）・チームの色（`MiniGameTeamColors`）・MVP の選び方（`MiniGameMvp`）を共通側へ移した。待ちの窓の板も丸ごと共通の `MiniGameTeamRoomPanel` にして、`SoccerRoomPanel`・`BaseballRoomPanel` は名前・メッセージの名前・中身の一言だけを持つ子にした（板の作り方も `PenmonScrambleSceneBuilder.TeamRoom.cs` で共通）
- **投げる人の決め方**: 守る側の人が打席ごとに交代で投げ、投げる子は**自分の子の中から**選ぶ（「投げる子を動かすのはその子の持ち主」と「打席ごとに交代」を両方守るため。1人のチームは全員が自分の子なので、ひとりと同じ）
- **2人のチームの打順は A1・B1・A2・B2**（案のまま）。編成にいない子は飛ばす。協力の打順も同じ決まり（4人なら各自の先頭の4人）。打順のカードは4枚に増やし、みんなでのときは左上に持ち主の名前を席の色で出す
- **1球はどの端末でも計算する**（`BaseballPitchSession`）: 投げ方と2人の入力の記録（歩ごと。値は送る大きさに丸めてから使う）だけで決まるようにして、記録を送り合う。相手の記録は届くまで最後の値が続くと見なし、違っていたら投げた所から計算し直す（1球は数百歩なので軽い）。ホストは結果が出た歩までの全員の記録がそろってから結果を決める（待つ上限 2.5 秒）。振った時刻は振った人の画面の時刻のまま判定される
- **ゲストが投げるときは先回り**: 投げた知らせを送ったら自分の端末で先に振りかぶって投げる。ホストの球はその知らせが届いてから振りかぶるので、ゲストの曲げる入力はホストの同じ歩より先に届く（ホストの画面・ホストの打つ人の画面で、球の曲がりが後から跳ばない）
- 結果の文字・走者の動き・試合の様子はホストの物を使う（ゲストの計算は、浮動小数の細かい違いで結果がずれることがあっても、試合はずれないように）
- 魔球の中の乱数は投げる人の端末で決めて送る（ホストは★の幅に収めて使う）
- ほかの人の番の間は、HUD の説明の所に「〇〇 が打つ番です」を出し、ボタン・スティック・球種の札は出さない
- MVP は打点（押し出しの四球も数える）。結果の間に左へ寄せたスコアボードの下に出す
- 待ちの窓の札は4枚になったので、札の幅を少し詰めた（300 → 240）
