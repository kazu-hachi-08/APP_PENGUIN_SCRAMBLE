## 0. 決まったこと（まとめ）

| 項目 | 決定 |
| --- | --- |
| 遊びの形 | **3対3の小さなサッカー**。壁で囲んだフットサルくらいのピッチ（ボールは外へ出ず跳ね返る。スローイン・オフサイド・ファウルは無し）。今の斜め見下ろし・おもちゃの3Dの見た目のまま |
| チーム | **チーム＝本編の編成の3体**。動かすのは1体で、残りはAI。ボールに近い子へ自動で切り替わり、交代ボタンでも切り替える |
| キーパー | 3体とは**別のおもちゃのキーパー**（AI。両チーム同じ強さ。操作しない） |
| ドリブル | **足元に吸い付く**。触れたら持ち、持ったまま歩く。シュート・パスで離す |
| ぶつかり合い | **スライディングでボールを奪う**。当たった子は少し（1秒くらい）転ぶ。本編ほど吹っ飛ばさない |
| シュート | 技1を**押してためて離す**（長いほど強く、いちばん強いと浮いた球）。向きはスティックで、**ゴールの方へ少し寄せる** |
| パス | 技2で**向いた方の味方の足元へ自動で**転がす。受けた子へ操作が移る |
| 必殺シュート | **属性ごとに4種**（氷・水・風・雷）。シュートの軌道が変わる。**ゲージはチームで1本**（ボールに触る・奪うとたまる）。★が高いほど強い |
| 個体差 | 必殺シュートの種類（属性）と強さ（★）だけ。**パワー（育成）と足の速さは効かせない**（オンラインで育成の差で勝負が決まらないように） |
| 試合 | **3分1本**。同点なら **PK戦（3本ずつ・守りも人が選ぶ。同点ならサドンデス）** |
| コース | **5スタジアム**（ストーリーの5ワールドの景色）。奥ほどCPUが強く、ワールドごとにピッチの仕掛けがある。**ストーリー連動で解放**（ゴルフと同じ） |
| カメラ | 横長のピッチを斜め見下ろしで**ほぼ全部見せ、ボールの方へ少し寄る** |
| ひとり | 自分の3体 対 CPU の3体 |
| オンライン | 最大4人。待ちの窓でホストが **対戦**（人を赤・青に分ける。1対1・2対1・2対2）か **協力**（全員で CPU と戦う）を選ぶ。**チーム分けはホストが決める** |
| 記録 | ベスト＝**1試合の得失点差の最高**（大きいほど良い）。special＝勝った回数 |
| 報酬 | **コイン**。出た分＋勝ち（PK勝ちは少し少なめ）＋得点。そのスタジアムで初めて勝ったらボーナス。本編より控えめ |

## サッカーのルール（案の数値はフェーズ 3・4・7 で決め直す）

### ピッチ

- 横長の長方形を壁で囲む。広さ 横 28 × 縦 16 マス（案）。四隅は斜めに切る（ボールが角に詰まらないように）
- ゴールは左右の壁の真ん中。幅 5 マス・高さ 1.6 マス（案）。ゴールの口を通り抜けたら点（浮いた球はバーより低いときだけ）
- 計算はすべて純C#（Unity の物理は使わない）。1/30 秒の固定の刻み（本編と同じ）。数値は `SoccerRules`（ルール）・`SoccerBalance`（ボールと動き）

### ボール

- 地面を転がり、摩擦で遅くなる。壁で跳ね返る（速さは 70% 残る。案）
- 高さを持つ。強いシュート・必殺シュート（水）・間欠泉のときだけ浮き、簡単な放物線で落ちる。浮いている間は持てない・パスを受けられない（頭の高さより低ければ受けられる。案）
- **持つ**: ボールに触れたら持つ（足元に吸い付く）。持っている間はボールは子の前に付いてくる。持っている子の歩く速さは ×0.85（案）
- 離れたボールは、直前に持っていた子だけ 0.4 秒は持てない（蹴った瞬間にまた拾わないように）
- 誰も触らないまま 8 秒（案）たったら、ボールが自分で一番近い子の方へ少し転がる（壁ぎわで止まって誰も取りに行かない詰まりを防ぐ。試合の確認でほかの手が要るかを見る）

### ペンモン（フィールドの3体）

- 3体とも同じ歩く速さ（種類の速さは効かせない）。属性と★は必殺シュートだけに効く
- 見た目は本編の `Penguin3D`。足元に席の色の輪（動かしている人の色。AI の子はチームの色のうすい輪）、頭の上に名前（オンライン）
- CPU のチームは、そのワールドの野生のペンモン3体（本編の雑魚と同じく暗い色。種類はスタジアムの定義表で決める）

### 操作

| 操作 | スマホ | PC（キーボード） | コントローラー |
| --- | --- | --- | --- |
| 移動 | 左の仮想スティック | WASD / 矢印 | 左スティック |
| シュート（持っている）/ スライディング（持っていない） | 右のボタン（大） | J | ×（南） |
| パス（持っている）/ ダッシュ（持っていない。案） | 右のボタン（中） | K | ○（東） |
| 必殺シュート | 技1の上のボタン（ゲージ満タンで光る） | L | △（北） |
| 動かす子を切り替える | 技2の上の小ボタン | Space | L1 |
| メニュー | 右上の ‖ | Esc / P | OPTIONS |

- ボタンの配置と見た目は本編のタッチ操作と同じ（本編で覚えた手のまま遊べるように）。中身のアイコンだけサッカー用に替える
- **シュート**: 押している間、足元にためゲージ（0.8 秒で満タン。案）。離すと蹴る。強さはためた長さ、いちばん強いと浮いた球になる。向きはスティック（倒していなければ向いている向き）で、相手のゴールの口へ最大 15°（案）寄せる
- **スライディング**: 向いている向きへすべる（0.35 秒。案）。持っている相手に当たったら、ボールを奪って相手は 1 秒転ぶ（案）。外すと自分が 0.5 秒起き上がれない（むやみに出させない）。待ち時間 1.2 秒（案）
- **パス**: 向いている向きの ±60° にいる味方のうち一番近い子の足元へ、届く速さで転がす（いなければ向いている向きへ弱く蹴る）。受けた子へ操作が移る
- **ダッシュ（持っていないときの技2。案）**: 0.5 秒だけ速く走る。待ち時間 3 秒。ボールを追いかけるため。要らなければフェーズ 3 で外す（何も起きないボタンにはせず、外すならボタンの中身を「パス」だけ見せる）
- **切り替え**: ボールを持っていないときに、ボールに一番近い味方へ自動で替わる（相手がボールを持っている・ボールが転がっている間。替わり続けてガタつかないよう、0.6 秒は替わらない。案）。交代ボタンでも、ボールに一番近い味方へ替わる
- 人が動かしている子へは替わらない（オンラインで同じチームに人が2人いるとき）

### キーパー（おもちゃのキーパー）

- ペンモンではない、ゼンマイで動くおもちゃの人形（オリジナルの見た目）。両チームに1体ずつ、強さは同じ（スタジアムでも変えない）
- ゴールの口の前を横に動き、ボールの来る所へ寄る。シュートが来たら、届く所なら飛びついて止める。止めたら少し持ってから、近くの味方の足元へ投げる
- 止められるか: ボールの速さ・キーパーからの距離・高さで決まる。真正面の弱い球はほぼ止め、端への強い球はほぼ入る。少しだけ乱数を混ぜる（ホストの `System.Random`）
- キーパーは操作しない・スライディングされない・ペナルティエリアのような線も無い（ルールを増やさないため）

### 試合の流れ

1. キックオフ: 両チームが自分の陣地に並び、ボールは真ん中。「キックオフ！」の合図でボールに触れられる（先攻は 1本目が赤、点を取られた側が次のキックオフ）
2. 3分（案）。点が入ったら「ゴール！」の演出（2 秒。全員の画面で止める）→ 並び直してキックオフ
3. 時間切れで点の多い方が勝ち。同点なら PK戦
4. 残り 10 秒からカウントダウン。時間はボールが動いている間も止まらない（演出の間だけ止める）

### PK戦

- 3本ずつ交代で蹴る。3本で同点ならサドンデス（1本ずつ、差がついたら終わり）
- **蹴る側**: スティックで狙う所（左・真ん中・右 × 低い・高い）を選び、シュートと同じくためて離す。ためすぎる（ゲージの赤い所）と枠を外れることがある（強い球ほど止められにくいが、外れる危険がある）。持ち時間 5 秒（案。過ぎたらそのときの狙いで弱く蹴る）
- **守る側**: 蹴る前に、飛ぶ方向（左・真ん中・右）を選ぶ（スティックで倒した方。決めなければ真ん中）。蹴った瞬間の選びで決まる（オンラインでは守る人の選びは蹴る人に見せない）。方向が合っていて、届く強さなら止める
- 蹴る子は3体の順（ひとりのチームは自分の編成の 1→2→3。人が2人のチームは交互）。PK戦では必殺シュートは使えない
- CPU が蹴る・守るときは、狙いと飛ぶ方向を乱数で選ぶ（CPU の強さで少し賢くなる。案）

### 必殺シュート

- ゲージはチームで1本（交代しても・誰が蹴っても同じゲージ）。ボールを持つ・奪う・パスが通るとたまる。満タンで必殺シュートのボタンが光る（数値はフェーズ 4）
- ボールを持っている子が押すと、その子の属性の必殺シュートを蹴る（ためは要らない）。出すときは本編と同じペンモンの顔のカットイン（0.6 秒。全員の画面で止める）
- キーパーは必殺シュートを止めにくい（止められる割合を下げる）が、必ず入るわけではない

| 属性 | 名前（案） | 軌道 | ★で変わる所 |
| --- | --- | --- | --- |
| 氷 | フリーズショット | まっすぐ飛び、当たった相手を凍らせて（動けない）貫く | 凍らせる時間 |
| 水 | アクアバウンド | 水切りのように地面で跳ねて進み、相手を飛び越える | 跳ねる回数（1 / 2 / 3） |
| 風 | トルネードカーブ | 大きく曲がって回り込む（右・左は蹴った向きのゴールの口から外れている側へ自動） | 曲がる大きさ |
| 雷 | イナズマショット | 一瞬消えて、少し先から超高速で現れる | 速さ・消える距離 |

### AI（フィールドの子）

- 役割: チームの3体に「前・真ん中・後ろ」の持ち場を配る（ボールの位置で持ち場ごと前後に動く）。ボールを持っている子と、一番近くでボールを取りに行く子は持ち場を離れる
- 持っているとき: 相手のゴールへ運ぶ。前が詰まっていたら空いている味方へパス。シュートが通る所（ゴールの口との間に相手がいない・距離が近い）ならシュート
- 持っていないとき（味方が持っている）: 空いている所へ走ってパスを受けやすくする
- 守るとき: 一番近い子がボールを持っている相手へ寄ってスライディング、ほかの子はゴールとボールの間を埋める
- CPU の強さ（スタジアムごと。`SoccerBalance`）: 気づくまでの遅れ・シュートの狙いのぶれ・スライディングの出しやすさ・パスを選ぶ賢さ。足の速さは変えない（速さで勝負が決まらないように）
- 人が動かしていない味方の子も同じ AI で動く（強さは「ふつう」で固定。案）

### オンライン

- 本編と同じく **ホストがすべて計算する**。ゲストは入力（移動の向き・押したボタン・ためている長さ）を変わったときに送る。ホストは毎秒15回、全員の位置・ボール・点・時間・ゲージ・起きたこと（シュート・ゴール・スライディング・必殺）をスナップショットで送る（`SoccerCodec`）。ゲストは届いた位置の間を補間して描く
- **対戦**: 待ちの窓で、ホストが席ごとに赤・青を決める（初めは P1・P3 が赤、P2・P4 が青）。片方に人がいないと開始できない
- **協力**: 人は全員赤、CPU が青。人が多いほど CPU が強くなる（気づく遅れ・狙いを人数で強める。案）。4人なら 4対4（案）
- チームの子: 人が1人のチームはその人の編成の3体（切り替えて動かす）。2人のチームは各自の編成の先頭＋席の若い人の編成の2番目（AI）。3人のチームは各自の先頭。切り替えは、人が動かしていない味方の子にだけ移れる
- 開始時に各自の編成の3体（種類・★）をホストへ送る（本編の `StageCodec.Party` と同じ形。届かなければ仮の3体）。移った先で「準備できた」をやり取りしてから始める（ゴルフと同じ）
- 切断: ゲストが落ちたら、その人の子は AI が動かす（3対3のまま続ける）。ホストが落ちたら全員タイトルへ
- 結果: 自分のチームが勝ったか、点、MVP（点を一番取った人）。報酬は各自の端末で保存。「スタジアムを選ぶ」（ホストだけ）で待ちの窓へ戻る

### 報酬（案）

- コイン ＝ 出た分 20 ＋ 勝ち 50（PK勝ちは 30）＋ 自分のチームの点 1 につき 8（5 点まで）
- そのスタジアムで初めて勝ったら +100
- オンラインの対戦・協力も同じ式（各自の端末で、自分のチームの結果で計算）
- 本編の1ステージの報酬と比べて控えめになるよう、フェーズ 7 で決め直す（ゴルフの 1時間に 800〜1400 くらいに合わせる）

## フェーズ 1: 入口とシーン・計算（Core）と試しのピッチ

### やること

1. `MiniGames/Soccer/Core`・`Soccer/Game` のフォルダと asmdef、テストの asmdef の参照
2. `MiniGameTable` に `"soccer"` の行（5スタジアム）。`SoccerCourseGuide` は全スタジアム「準備中」
3. `SoccerScene` を `SoccerSceneBuilder` で生成し、Rebuild とビルドの一覧に足す。「もどる」でミニゲーム画面へ
4. ピッチの定義（`SoccerPitchDef`。コードの定義表）: 広さ・壁・ゴールの口・四隅の切り・地面の種類の範囲（仕掛けはフェーズ 6 で使う）・キックオフの並び
5. 計算（`SoccerWorld`）: 固定の刻みで進める。子の移動・ボールの転がり・壁の跳ね返り・浮いた球の放物線・持つ / 離す・シュート・ゴールの判定。表示と音へは起きたこと（`SoccerEvent`）をイベントで出す
6. 汎用の当たりの計算が要れば `GolfGeometry` から `MiniGames.Core` へ移す（ゴルフのテストが通ったまま）
7. テスト: 蹴った球が止まる距離・壁の跳ね返り・持つ / 離した直後に拾わない・ゴールの口を通ると点・バーより高い球は入らない
8. 開発用メニュー `Tools > PenmonScramble > Soccer > 試しのピッチ`（仮の見た目。板と球と円柱の子）

### 遊べる状態

ミニゲーム画面にサッカーのカードが出る（スタジアムは「準備中」）。試しのピッチで1体を動かし、ボールを運んでゴールへ蹴り込める。

## フェーズ 2: 見た目と操作・キーパー

### やること

1. ピッチの3D: 芝のおもちゃの地面・白い線・低い壁（ボードのような柵）・ゴールの枠と網（網が揺れる）。地面の絵は今のワールドの絵を使う
2. ボール: おもちゃのサッカーボール。転がりの回転・浮いたときの影
3. 子: `Penguin3D` に蹴る・ためる・スライディング・転ぶ・ゴールで喜ぶ・取られて悔しがるの動き（動きの定義に足す）
4. 操作: 上の表のとおり（タッチ・キーボード・コントローラー）。シュートのためゲージ（足元の弧）。ボタンは本編の見た目を使い回し、アイコンをサッカー用に
5. キーパー: おもちゃのキーパーの見た目と動き・止める判定（Core）・投げ返し。テスト（真正面の弱い球は止める・端の強い球は入る）
6. カメラ: ピッチをほぼ全部見せ、ボールの方へ少し寄る。ゴールの瞬間に少し寄る
7. HUD（仮）: 点・時間
8. 音: 蹴る音（強さで変える）・壁・ゴールの網・キーパーが止める・ホイッスル

### 遊べる状態

試しのピッチで、本番の見た目と操作で、キーパーのいるゴールへ気持ちよく蹴り込める（タッチ・キーボード・コントローラー）。

## フェーズ 3: 3対3とAI

### やること

1. チーム: 両チーム3体＋キーパー。動かす子の切り替え（自動・交代ボタン）。動かしている子の足元の輪
2. パス・スライディング・転ぶ・奪う（Core。テスト: パスが向いた方の味方へ届く・スライディングで奪う・外すと起き上がれない）
3. AI（`SoccerAi`）: 持ち場・運ぶ・パス・シュート・取りに行く・守る。強さの調整値
4. **試合の確認**（`Tools > PenmonScramble > Soccer > CPUの試合の確認`）: CPU 同士を自動で何試合も戦わせ、1試合の点の数・ボールが誰にも触られない時間・壁ぎわの詰まり・強さの差で勝ち負けの割合が変わるかを出す（ゴルフのコースの確認と同じ考え方。Core の計算だけで速く回す）
5. 動かす子の切り替えのガタつき・AI の団子（全員がボールに群がる）を確認で見つけて直す

### 遊べる状態

試しのピッチで、自分の3体（切り替え・パス・スライディング）対 CPU の3体の試合ができる。

## フェーズ 4: ひとりで1試合（試合の流れ・PK戦・必殺シュート・結果）

### やること

1. 試合の流れ（`SoccerMatch`）: キックオフ・3分・ゴールの演出と並び直し・残り10秒・時間切れ・同点で PK戦
2. PK戦（`SoccerShootout`）: 3本ずつ・サドンデス・蹴る狙いとため・守る方向・持ち時間・CPU の選び方。テスト（本数・サドンデスの終わり・守りが合えば止まる）
3. 必殺シュート4種（Core。★で強さ）・チームのゲージ・カットイン・テスト
4. スタジアム1「海岸」（仕掛けなし。CPU の強さ ★1）。`SoccerCourseGuide` でスタジアム1を遊べるに
5. HUD: 点・時間・ゲージ・必殺のボタン・ゴールの演出・PK戦の表（○×）
6. 結果: 勝ち負け・点・得失点差・コインの内訳・ベスト更新・初勝利ボーナス・「もう一度」「スタジアムを選ぶ」「ロビーへ」。報酬と記録を書いて保存（`SoccerReward` → `MiniGameReward`）
7. 試合中のメニュー（‖ / Esc）: つづける・試合をやり直す・設定（音量）・ミニゲーム画面へ（本編の `StageMenu` の見た目を使い回す。遊び方はフェーズ 7）
8. 仕様書 §13.4 を書き始める

### 遊べる状態

ミニゲーム画面から「ひとりで」スタジアム1で3分の試合をし、同点なら PK戦、結果でコインとベストがもらえる。

## フェーズ 5: オンライン（対戦・協力）

### やること

1. 待ちの窓に「サッカー」の札と `SoccerRoomPanel`（スタジアム・対戦 / 協力・席ごとの赤・青。ホストが押して入れ替える）。ゲストは見るだけ。`scramble.soccer.choice` / `.ask`
2. 通信（`SoccerCodec`）: ゲストの入力・ホストのスナップショット・起きたこと。ゲストは計算しない写しで描く（補間）
3. チームの組み方（人の数ごとの子の割り当て）・人が動かしていない子への切り替え・協力の CPU の強さの上乗せ
4. 開始時の編成の受け渡し・「準備できた」・切断（ゲストの子は AI に）
5. PK戦のオンライン: 守る人の選びを蹴る人に見せない（蹴った瞬間にホストが決める）
6. 結果: 勝ち負け・MVP・報酬は各自。「スタジアムを選ぶ」（ホストだけ）で待ちの窓へ
7. ミニゲーム画面の「みんなで」から、遊ぶもの＝サッカーで「みんなで遊ぶ」の窓を開く
8. 仕様書 §8・§13.4 を直す

### 遊べる状態

友達と4人まで、対戦（1対1・2対1・2対2）と協力（全員 対 CPU）でスタジアム1を遊べる。待ちの窓でボスラッシュ・ゴルフ・サッカーを切り替えられる。
